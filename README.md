# E_COMMERCE
This is a full-stack eCommerce web application built using PHP, JavaScript, MySQL, and XAMPP. The project demonstrates practical web development skills, including database integration, user authentication, product management, and dynamic frontend interactivity.
Features
Product Catalog – Browse and search products by category
Shopping Cart – Add, remove, and update items in real time
User Authentication – Register, login, and manage accounts
Admin Panel – Add, update, and delete products; manage orders
Responsive Design – Optimized for desktop and mobile devices
Checkout Workflow – Users can place orders and view order history
Dynamic Interactions – Real-time updates using JavaScript and AJAX
Technologies Used
Frontend:
HTML – Page structure
CSS / Bootstrap – Styling and responsive design
JavaScript – Client-side interactivity
jQuery – DOM manipulation and AJAX calls
Backend:
PHP – Server-side processing and database communication
MySQL – Database management and queries
JSON – Data exchange between frontend and backend
AJAX – Dynamic content updates without page reloads
Server / Environment:
XAMPP – Local server environment with Apache and MySQL
